🗄️ 数据库管理指令台

复制 SQL 语句，去 Cloudflare D1 Console 执行

🔍 查询与查看

查看所有用户的简略信息（不含头像数据，页面加载快）：

SELECT id, username, password, nickname, qq_number, birthday, gender, location, status, created_at FROM users;

查看所有人的在线状态（谁在什么设备上登录了）：

SELECT username, device_ua, created_at FROM sessions;

🚫 封禁与解封

封禁某个违规用户（将其状态改为 banned，他将无法登录）：

UPDATE users SET status = 'banned' WHERE username = '填用户名';

解封某个用户（恢复为 active）：

UPDATE users SET status = 'active' WHERE username = '填用户名';

🔑 密码重置

当用户发邮件申请忘记密码后，手动帮他改成新密码：

UPDATE users SET password = '新密码' WHERE username = '填用户名';

🧹 清理与维护

强制踢掉所有人的登录状态（重置 sessions 表，用于大更新或测试互踢）：

DELETE FROM sessions;

彻底删除某个用户（不可逆）危险操作 

DELETE FROM users WHERE username = '填用户名';
