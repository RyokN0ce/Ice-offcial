🗄️ D1 数据库结构 (ice-db)

1. users 表

存储所有注册用户及资料。

CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL,
  nickname TEXT,
  qq_number TEXT,
  avatar_url TEXT DEFAULT '',
  birthday TEXT DEFAULT '',
  gender TEXT DEFAULT '',
  location TEXT DEFAULT '',
  status TEXT DEFAULT 'active',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

2. sessions 表

用于多设备互踢（登录态检测）。当有人登录时，会在这里记录，如果已有记录则触发强制下线提示。

CREATE TABLE sessions (
  username TEXT PRIMARY KEY,
  token TEXT NOT NULL,
  device_ua TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

🔄 全局通信机制 (postMessage)

你的网站采用了外层框架 + 内层 iframe 的架构，所有跨页面通信均通过 window.postMessage 完成，这是保证不刷新的核心。

消息类型 发送方 接收方 作用
navigate 导航/内页 外层框架 命令内容框切换页面
pageLoaded 内页 导航栏 通知导航栏更新高亮与标题
updateAuth 登录/注册页 外层框架 -> 导航栏 通知导航栏刷新右上角用户状态
settingsToggle 导航栏 外层框架 撑开/收起顶部 iframe 高度，防遮挡

⚡ Worker 接口与安全配置

所有后端逻辑都在 Cloudflare Worker 中，绑定了 D1 数据库，并配置了 CORS 跨域。

  • API_BASE: https://api.iceapis.dpdns.org
  • 绑定变量名: DB (必须全大写)
  • 防火墙: 在 Cloudflare 的 WAF 里配置了限流，防止 F5 狂刷。
💡 关于维护模式：去根目录改 res/state.xml，把 normal 改成 maintenance，所有用户就会死死锁在错误提示页。非常适合大更新或修 Bug 时紧急熔断。
