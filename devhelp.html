🗄️ 二、 核心数据文件结构

1. 维护状态库：res/state.xml

作用：用于控制全站是否进入“维护模式”。index.html (外框) 启动时会读取此文件。

<?xml version="1.0" encoding="UTF-8"?>
<status>
    <!-- 
      可选值：
      normal       = 正常访问，加载 main.html
      maintenance  = 维护模式，contentFrame 强制加载 tools/error.html
    -->
    <current>normal</current>
</status>

2. 用户白名单库：res/userlist.xml

作用：作为账号登录的唯一凭证数据源，login.html 会拉取此文件比对账号密码。

<?xml version="1.0" encoding="UTF-8"?>
<users>
    <user>
        <name>RyokN0ce</name>
        <password>ice2026</password>
        <status>active</status> <!-- active 正常, banned 封禁 -->
    </user>
</users>

3. 背景音乐列表：res/mainaudio/playlist.json

作用：供 bgmswitcher.js 读取，自动生成设置面板中的音乐下拉菜单。

[
  "bingbingbing.mp3",
  "ice-ambient.mp3"
]
注意：将 .mp3 文件放入同目录后，在此 JSON 中添加文件名。**最后一行不能有逗号**。

🔄 三、 全局通信机制 (postMessage)

网站采用了外层容器 (index.html) + 内层内容 (main.html 等) + 导航栏 (nav-container.html) 的 iframe 架构，所有跨页面行为均通过 window.postMessage 传递。

消息类型 (type) 发送方 接收方 载荷 (data) 作用说明
navigate 导航/内容页 外层框架 url: 'xxx.html' 命令 contentFrame 切换页面
pageLoaded 内容页 导航栏 path: '/xxx' 通知导航栏高亮对应菜单
setActive 外层框架 导航栏 page: 'xxx.html' 显式设置导航栏高亮状态
settingsToggle 导航栏 外层框架 open: true/false 通知框架撑开/收起顶部 iframe
updateAuth 登录页 导航栏 无 通知导航栏刷新右上角状态
themeChange 导航栏 外层框架 theme: 'light/dark' 同步亮暗色主题给内容 iframe

🎨 四、 新增页面的标准流程

当你需要新加一个类似 pages/supportmain.html 的页面时，请遵循以下规范：

  1. 复制模板：复制一个现有页面（如 aboutus.html），删掉内部内容，保留 <head> 里的 CSS 变量。
  2. 引入通信：确保页面底部有 window.parent.postMessage({ type: 'pageLoaded', path: window.location.pathname }, '*');，否则导航栏不会高亮。
  3. 返回逻辑：所有返回主页的按钮，必须写成 window.parent.postMessage({ type: 'navigate', url: 'main.html' }, '*');（不能直接用 href 跳转，否则会破坏 iframe 框架）。
  4. 主题同步：确保底部有一段读取 localStorage.getItem('ice-theme') 的脚本，以保持亮暗色统一。
💡 本地调试须知：因为包含 fetch 请求 XML/JSON，不能直接双击 HTML 打开，必须使用 Live Server 或本地服务器环境。
